💡 What: Added global `:focus-visible` outline styles to the `.btn` class in `base.html`.
🎯 Why: Keyboard users previously lacked clear visual feedback when tabbing through buttons, making keyboard navigation difficult and unintuitive.
📸 Before/After: Not applicable (CSS behavior change rather than static layout change).
♿ Accessibility: Resolves 'Missing focus indicators on interactive elements' issue by providing a distinct focus ring for keyboard navigation while avoiding unneeded focus rings for mouse clicks.
