## Summary of Accomplishments

Hardened the `/system/upgrade` route against broken pulled code by adding pre-flight
syntax checks, dynamic binary path resolution, and an automated rollback mechanism.

### Key Deliverables & Implementation Details:

1. **Pre-upgrade SHA capture**:
   - `_get_current_sha()` in `src/pit_panel/web/routes/system.py` runs
     `git -C /opt/pit-panel rev-parse HEAD` to capture the active SHA before any
     destructive operation, ensuring a reliable rollback target.

2. **Dynamic binary resolution**:
   - `_resolve_uv_bin()` searches `shutil.which("uv")` first, then falls back to a
     prioritized list (`/usr/local/bin/uv`, `/usr/bin/uv`,
     `/opt/pit-panel/.venv/bin/uv`, `/root/.cargo/bin/uv`), raising
     `FileNotFoundError` only if all candidates are exhausted.
   - `python_bin = sys.executable` is used for `compileall`, guaranteeing the same
     interpreter that runs the FastAPI daemon.

3. **Pre-flight syntax compilation**:
   - Inserted `[python_bin, "-m", "compileall", "-q", f"{INSTALL_DIR}/src"]` after
     `uv sync` so any merge conflict markers, partial downloads, or syntax errors
     cause a non-zero exit before service reload.

4. **Automated rollback**:
   - On any step failure, executes `[ROLLBACK]`-prefixed logs and runs:
     `git reset --hard <original_sha>` → `uv sync` → `systemctl daemon-reload`.
   - Rollback failures are logged but do not crash the endpoint.

5. **Response log formatting**:
   - `OK   <cmd>` on success, `FAIL <cmd>: <err>` on failure,
     `[ROLLBACK] OK|FAIL <cmd>` on rollback.

6. **Test suite & verification**:
   - `tests/unit/test_system.py` extended with 5 new tests:
     - `test_resolve_uv_bin_found`
     - `test_resolve_uv_bin_fallback_found`
     - `test_resolve_uv_bin_not_found`
     - `test_system_upgrade_compile_failure`
     - `test_system_upgrade_rollback_failure`
   - **Ruff**: `uv run ruff check src/pit_panel/web/routes/system.py tests/unit/test_system.py` → All checks passed
   - **Pytest**: `uv run pytest -q tests/unit/test_system.py` → 7 passed in 1.88s
