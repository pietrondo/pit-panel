## 2025-02-18 - Optimized authentication session lookups
**Learning:** High-frequency backend routes often call `validate_session` on every request. Since this route requires a database check (a join on User and Session), it introduces overhead for every authorized API or HTMX polling route. Adding an in-memory short-lived cache bypasses this DB lookup. However, it's also important to clear corresponding cache keys when a session is revoked or the cache hits a size limit.
**Action:** When working on backend optimizations that query DB state heavily for every authenticated route, consider adding short-lived caching `(time.monotonic() - cached_at < TTL)` in python to avoid unnecessary database allocations.
